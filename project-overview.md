## The Data Science Project – General Instructions

---

## 1. Overview

The project is a vital component of any broad-topic data science course and plays a significant role in specialized courses as well. It has two primary goals:

- Demonstrate **proficiency** in data science methodology by executing all phases of the data science process from defining a problem to implementing and presenting a solution.
- Deepen experience in data science concepts and technologies by gaining in-depth experience in an area of your choice, whether it involves exploring systems, algorithms, or applying class concepts in greater depth.

The project is open-ended, encouraging you to explore or deepen your understanding of a data science area that excites you. Focus on delivering quality work, and make the most of the process. If you encounter difficulties, do not hesitate to seek support. You may discuss your project idea with the instructor before you start.

---

## 2. Project Teams

- You are expected to work in teams of 2 students.
- You may choose to work alone if you prefer.
- Teams of 3 are permitted only if class size requires it, and this must be approved by the instructor.

---

## 3. Project Topics

You are expected to choose a topic for your project. There are two ways to start a topic for the data science project:

- **Real-world data science problem**  
  Explore a data problem in the real world. You may not find a perfect dataset in this case. This approach emphasizes problem definition, data sourcing, data cleaning, and feasibility analysis.

- **Pre-defined problem or dataset**  
  Select an existing problem or dataset that is well defined and has a clear benchmark. This approach emphasizes data analysis, model selection, evaluation, and comparison.

In this course, the first approach is highly recommended. You are encouraged to start with data “in the wild” and practice the data management skills you have learned in this course. However, for completeness of the project, you must still complete the full data science methodology from start to finish.

The end result should be a well-documented data science project that:

- Demonstrates your understanding of the data science process.
- Properly manages the data throughout the lifecycle.

## 4. Data Sources

There are many different sources of data in the real world. In general, datasets can be classified into three main categories:

- **Structured data**  
  Data organized in a fixed, well-defined format, usually tabular. Typical examples: CSV, TSV, Excel, time-series data, spatial data.

- **Unstructured data**  
  Data not organized in a fixed, well-defined format. Typical examples: text, images, audio, video.

- **Semi-structured data**  
  Data with flexible structure. Typical examples: JSON, XML, HTML.

Data may be stored in a variety of formats and sources, including but not limited to:

- Flat files: CSV, TSV, Excel spreadsheets (`.csv`, `.tsv`, `.xlsx`, etc.).
- Relational databases: MySQL, PostgreSQL, SQLite, Microsoft SQL Server.
- Cloud-based relational databases or data warehouses: Snowflake, Amazon Redshift, Google BigQuery, Azure Synapse.
- NoSQL databases: MongoDB (document), Cassandra (wide-column), Redis (key-value), Neo4j (graph).
- Cloud storage and distributed file systems: Amazon S3, Google Cloud Storage, Azure Blob Storage, Hadoop HDFS.
- Web APIs: REST or GraphQL APIs, typically returning JSON or XML.
- Public repositories or portals: Kaggle, Data.gov, UCI Machine Learning Repository, etc.

For this project:

- You must work with **two different sources of data** from the above categories and formats.
- To collect these datasets, you will likely need to do some research on the web.

Some suggested sites for data collection:

- Kaggle: https://www.kaggle.com/
- Data.gov: https://www.data.gov/
- Dataset Search: https://datasetsearch.research.google.com/
- OpenML: https://openml.org/
- Public APIs: https://github.com/public-apis/public-apis

You are highly encouraged to apply what you have learned in this course to store, clean, and analyze the data from these sources.

## 5. Project Deliverables

There are four main deliverables:

1. **Project Proposal**  
   A written proposal including:
   - Project topic  
   - Tentative data sources  
   - Algorithms to be used  
   - Main challenges to be addressed  

2. **Project Progress Report**  
   A written mid-project report, including:
   - Updated version of the proposal  
   - Detailed datasets and data management steps  
   - Detailed approach  
   - Remaining concerns  

3. **Project Repository**  
   A GitHub repository containing all code implemented during the project.

4. **Project Presentation (~10 minutes)**  
   A final presentation demonstrating your project to the class.

---

## 6. Notes on the Project

1. **Use of External Work**  
   - Research is encouraged.  
   - You are expected to **cite** all external sources in the project proposal and progress report.  
   - You must execute your solution independently and must not copy code from external sources.

2. **Use of Generative AI**

   The use of generative AI is **allowed** for:

   - Brainstorming project ideas.
   - Finding datasets and APIs, and getting feedback or suggestions on the project.
   - Helping with implementation, such as partial code completion or debugging.

   The use of generative AI is **strictly prohibited** for:

   - Generating any submitted documents (e.g., project proposal, progress report).
   - Generating the project repository directly.
   - Any other case that delegates core project work to generative AI.
